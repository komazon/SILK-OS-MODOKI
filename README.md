# SILK OS
Scratchで動くOSもどき！CLIで操作も簡単！  

## **開発理由**  
久しぶりに何か作りたかったから。  

## **コンセプト**  
限界ブロック数節約  

## **特徴** 
引数間などの空白にとても厳格(手抜k
## **使用できるコマンド**  

### ls  
##### 使用例:  
`ls /`  

### kuminote  
##### 使用例:  
`kuminote cheat_sheet.txt`  
※カレントディレクトリにあるファイルしか読み込めません  
※保存は↑+S  

### cd  
##### 使用例:  
`cd user/`  


### mkdir  
##### 使用例:  
`mkdir test_folder`  
※これはCurrentに作成されます  


### touch  
##### 使用例:  
`touch test.txt`  
※これはCurrentに作成されます  

### echo  
##### 使用例:  
`echo ジーク・ジオン！`  
### newuser
引数なし。(対話型です)  


### rm
##### 使用例:  
`rm test_folder/`  

### todrun
##### 使用例:
`コマンド名("引数1")("引数2")`  
※入っているコマンドは使えます  
※カレントディレクトリ以外も読み込めたと思います


### about
##### 引数なし。ディストリビューションの詳細が出ます。
